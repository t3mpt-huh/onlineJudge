# 🧑‍⚖️ Online Judge Platform

**Live Link:** _Currently offline_  
**Note:** ⚠️ The compiler backend has been shut down as of **December 2024**.

## 📌 Overview

A full-fledged Level-4 Online Judge platform where users can:
- Solve competitive programming problems
- Submit code and get instant verdicts
- View their past submissions
- Admins can manage problems and users

Developed as part of a solo project during my externship at [AlgoUniversity (YC-backed)](https://algouniversity.com/), this platform simulates real-world online judges like Codeforces, LeetCode, etc.

## 🚀 Tech Stack

- **Frontend**: React.js, HTML, CSS, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **DevOps**: Docker
- **Deployment**: AWS, Vercel, Render

## 🔧 Features

### 👨‍💻 User Panel
- Register/Login with authentication
- Browse programming problems
- Submit code for evaluation
- View verdicts (Accepted, Wrong Answer, etc.)
- Track previous submissions

### 🛠️ Admin Panel
- Add, Edit, and Delete problems
- View all registered users
- Access submission details

### ⚙️ Code Execution (Now Disabled)
- Code execution handled via a Docker-based secure containerized backend (shutdown in Dec 2024)

## 🧪 Security Measures
- Input validation and script filtering
- Containerized execution to prevent malicious code from affecting the server
